# LTC 模型弊端分析与改进方向

- 日期：2026-09-05
- 依据代码：`gait_grf/models.py`、`gait_grf/data.py`、`gait_grf/train.py`、`gait_grf/constants.py`（ncps 1.0.1）
- 依据结果：`runs/tracer_loso8/`（基线）、`runs/ltc_full/`（首次完整 LTC，见 `docs/experiment-log.md`）
- 结论一句话：**容量不是瓶颈，表征才是。改进主方向是构建跨受试者可迁移的物理先验特征前端（关节角 + 压力摘要），而非加大模型。**

## 1. 现状基线

| 运行 | 配置 | LOSO 合成幅值 Pearson r |
|---|---|---|
| tracer_loso8 | LTC hidden 32×1、dropout 0、**仅 5 epochs** | 0.8525 ± 0.0607 |
| ltc_full | LTC hidden 128×2、dropout 0.3、早停（27–67 epochs/折） | **0.8689 ± 0.0718** |

**关键证据——容量论已被否定**：hidden 128×2 + ~45 epochs 均值（约 9 倍于 tracer 的训练轮数、4 倍宽度、2 倍深度）只比 5 epochs 的 tiny tracer 提升 +0.017 r。继续堆模型规模不会有回报。

**关键证据——跨受试者方差是主要误差源**：
- z7 各折最差（resultant r 0.681，其余折均 ≥ 0.879），且训练得最久（67 epochs）仍未收敛到别的折水平；
- **z8 的右足 vx r 仅 0.303**（z7 为 0.588，其余折 0.67–0.80）—— 左右足同一模型、同侧输入结构，唯独个别受试者的右足水平力崩坏，指向受试者特异的传感器绑扎/佩戴差异，而非模型能力。

## 2. 弊端分析（按影响排序）

### 2.1 核心：原始传感器四元数不可跨受试者迁移

`data.py:150`（`extract_features`）直接把 `constants.py:5` 的 28 维四元数（7 个 IMU 的**世界坐标系朝向**）作为输入。同一身体姿态下，不同受试者因传感器绑扎角度不同，四元数取值完全不同。

- `data.py:261` 的 StandardScaler 只能消各维均值/方差，消不掉「世界系 + 绑扎偏移」的受试者特异性；
- LOSO 协议 + 仅 7 个训练受试者，模型必然记住训练者的四元数→GRF 特异映射，在留出者上失效；
- 反证：90 通道鞋垫压力对所有人布局相同（产品固定），是天然受试者不变的——两类输入可迁移性不对称，正是 LOSO 方差的来源；
- 本项目此前修复的板↔脚翻转（`data.py:154`）本质是同一类问题（共享模型需要受试者无关表征），四元数是尚未处理的另一半。

### 2.2 全连接 wiring，并非论文中的 NCP

`models.py:24` 用 `ncps.torch.LTC(input, units=int)`，ncps 1.0.1 中 int units 默认 **FullyConnected** wiring，不是 Lenz et al. 的稀疏 AutoNCP 结构。

- 2 层 hidden 128 全连接 LTC 约 6.6 万参数，在仅 ~2100 个窗口（226 trial，每 trial 1.4–2.4s）的数据上易过拟合受试者特异细节；
- LTC 的自定义 ODE 反传极慢：实测每折 ~29 分钟、全量 8 折 ~3h55m（RTX 4090，GPU 利用率仅 17%，瓶颈在 CPU 端），导致超参搜索事实上不可行。

### 2.3 无梯度裁剪

`train.py:139-146` 的训练循环无 `clip_grad_norm_`。LTC 的 ODE 式反传易梯度爆炸，Adam lr=1e-3 裸跑存在训练不稳定与局部最优风险。

### 2.4 LTC 兼任「感知 + 动力学」两个角色

120 维原始输入（28 四元数 + 90 压力 + 2 和，`constants.py:24`）直接灌入 LTC。NCP 系列论文的标准架构是前置感知网络，LTC 只负责低维动力学。当前全连接 LTC 被迫消化 90 路高冗余压力通道，放大了 2.1 与 2.2。

## 3. 主推方向：物理先验特征前端（关节角 + 压力摘要）

把输入从「传感器空间」换到「身体空间」：

| 输入块 | 现状 | 改为 | 维度 |
|---|---|---|---|
| 四元数 | 7 IMU 世界系朝向 | 相邻传感器相对四元数 → 关节角：髋(trunk↔thigh)、膝(thigh↔calf)、踝(calf↔foot) × 双腿 + 躯干绝对前倾 | ~20 |
| 压力 | 45 通道 × 2 + 2 和 | 每足：总压力 + CoP（需鞋垫布局坐标；没有则按通道分区做足跟/中足/前掌区域和） | ~6–8 |
| **合计** | **120** | **~26** | |

相对四元数 `q_rel = q_parent⁻¹ ⊗ q_child` 中，世界系与两侧共有的绑扎偏移被消去，剩下的关节几何是解剖学锚定、跨受试者成立的量。

**预期收益与弊端的对应**：治本 2.1（表征可迁移）；缓解 2.2/2.4（输入 120→26，感觉权重降 ~4.6 倍，可缩到 1 层 hidden 64，每折预计 <5 分钟）；`models.py` 无需改动，只改 `data.py`/`constants.py`，训练/LOSO/指标管线全复用。

### 实施注意（两个坑）

1. **两组四元数分量顺序不同**：大腿/小腿/躯干用 q1–q4，双足用 q0–q3（`constants.py:5`），来自不同系统，wxyz vs xyzw 需先实证确认（静止段姿态一致性、关节角曲线是否平滑合理）。踝关节（calf↔foot）恰跨两系统，风险最高。
2. **先便宜后贵验证**：先跑岭回归/线性探针 LOSO 对比新旧特征（秒级出结果，tracer 阶段已有此方法），确认 vy r 提升后再上 LTC 全量。

### 验证路径

1. 线性探针（Ridge）LOSO：raw 120 维 vs 关节角+压力摘要 ~26 维，比 vy/resultant r；
2. LTC 单折计时与精度抽查（选 z7 折——最难折最有信息量）；
3. 全量 8 折，与 `docs/experiment-log.md` 中基线对比。

## 4. 次要改进项（顺手做）

- **梯度裁剪**：`train.py` 训练循环加 `torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)`，5 行，LTC 稳定性刚需；
- **AutoNCP 稀疏 wiring**：换 `ncps.wirings.AutoNCP`（论文正统用法），进一步正则化 + 提速。属第二步——表征不解决，wiring 救不了 LOSO；
- 学习率可试 3e-4（配合裁剪）。

## 5. 明确不推荐的方向

- 继续加大 hidden/层数/epochs：容量论已被 1 节证据否定；
- 换更大模型（Transformer 等）：数据量（~2100 窗、7 训练受试者）撑不起，只会加剧受试者过拟合。

## 6. 实现与验证追记（2026-09-05 下午）

### 6.1 四元数约定的实证结论（修正 2.1 的前提）

对传感器数据本身（未使用 Noraxon）做了系统排查，结论修正了第 3 节的设计前提：

1. 四元数为单位范数（226 文件全量检查，离开 [0.98,1.02] 的比例 0%）、时间平滑、各环节相对静态基线的摆幅层级符合人体先验（躯干 1–15° < 大腿 ≈ 小腿 2–40° < 足 24–174°）——是有效的环节朝向序列；
2. 但四种循环分量读法（w 位置的 4 种循环置换，两两相差固定共轭变换 $T^k$）下，静态站立帧的旋转轴与任何候选世界轴（x/y/z）的 |cos| 均在 0.29–0.79，无一接近 1 —— **不存在共享重力对齐世界系**；
3. 结论：每个 IMU 的四元数是**相对各自上电时刻姿态**的朝向序列。真解剖关节角不可恢复；分量顺序是全局固定变换，对跨受试者迁移无影响（学习器可见的信息内容不变），无须也无法从数据内辨识；
4. 推论：可迁移特征的正解是**相对自身静态基线的运动** $\Delta M(t) = M(t_0)^{-1} M(t)$（各 trial 开头站立帧取基线），上电参考系在乘法中严格相消；残余的受试者特异性仅剩绑扎旋转（对 rotvec 轴向有污染，对角度幅值无污染）。

### 6.2 实现落地（ticket #7）

- `gait_grf/features.py`（新增）：`derive_kinematic_features` 两档模式
  - `kinematic`（51 维）：逐传感器基线相对 rotvec 7×3 + 关节相对 rotvec 6×3（ΔM_p⁻¹⊗ΔM_c，共模晃动相消）+ 压力摘要 12（每足 总和/峰值/接触面积/三区段和，区段为启发式）；
  - `kinematic_min`（25 维）：仅角度幅值 + 压力摘要，完全不含受绑扎污染的轴向信息；
- `data.py`：`extract_features`/`load_aligned_trial`/`GRFSequenceDataset` 增加 `feature_mode`（缓存键含 mode，raw 路径与基线完全一致）；`discover_trial_pairs` 过滤无效 trial；
- `constants.py`：`INVALID_TRIALS = {(z1,03),(z1,04)}`（LQW03/04 IMU 全零，连同其测力台数据排除，226→224 trial）、`STATIC_BASELINE_FRAMES = 8`；
- `train.py`：`--features {raw,kinematic,kinematic_min}`，默认 raw（基线可复现），config 随 checkpoint 保存；
- `probe.py`（新增）：帧级 Ridge LOSO 特征探针；零四元数帧以单位四元数填充（LQW03/04 已整对排除，其余文件无此情况）。

### 6.3 线性探针验证结果（LOSO Ridge，帧级，全部 224 trial）

| 特征模式 | 维数 | vy r (左/右) | 合成幅值 r |
|---|---|---|---|
| raw（基线输入） | 120 | 0.785±0.158 / 0.847±0.083 | 0.506±0.144 |
| **kinematic** | 51 | **0.874±0.055 / 0.893±0.075** | **0.638±0.093** |
| kinematic_min | 25 | 0.875±0.045 / 0.892±0.076 | 0.617±0.121 |

- 合成幅值 r +0.13、跨折 std −35%；改善最大的正是绑扎敏感的水平轴（左 vx 0.680→0.805，std 0.241→0.082）；
- 个案：z5 左 vx 0.076→0.866，z4 合成幅值 0.306→0.696（灾难折被救回）；
- z7 仍为离群折（0.294→0.425，部分改善）——受试者特异问题（绑扎/佩戴差异）未能完全由特征前端消除，与 ltc_full 的逐折观察一致；
- 线性探针数值不可与 LTC 直接比（模型类不同），仅用于固定模型下对比特征。
